09 / Why Async

BRedis jobsmall metadata
CWorker AIvariable latency
DAccess log updatedfinal status
Trade-offFast API, scalable worker

14 / Vector Search
How Matching Works

Face image trở thành vector.

Worker biến snapshot thành embedding, query Qdrant, nhận candidate gần nhất, rồi verify lại employee trong PostgreSQL.

512DFacenet512 embedding space.
cosineĐo độ gần giữa vector snapshot và vector employee.
payloadQdrant giữ employee/model metadata.
verifyBackend data vẫn kiểm tra active/inactive.
AI internalsImage -> embedding -> nearest vector -> decision

35 / Failure Modes
Error Design

Không phải lỗi nào cũng là denied.

  • denied: ảnh hợp lệ nhưng không đủ ngưỡng hoặc employee inactive.
  • error: ảnh không đọc được, no-face, multi-face hoặc dependency lỗi.
  • Phân biệt status giúp admin debug nhanh hơn.
ReliabilityMake failure explainable
