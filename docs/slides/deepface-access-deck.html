01 / Why
Problem

Không chỉ là “nhận diện một ảnh”.

06 / Async Request
Queue Pattern

Request trả nhanh, AI xử lý sau.

Backend tạo log processing và đẩy job vào Redis. Worker cập nhật kết quả cuối khi xử lý xong.

APIValidate + upload imagefast response
DBCreate initial access logprocessing
QPush small Redis jobmetadata only
AIWorker runs DeepFacevariable latency
UIRefresh log resultfinal status
QueueDecouple HTTP latency from model latency

12 / Enrollment Pipeline
Register Face

Ảnh nhân viên trở thành embedding.

Enrollment cần đúng một khuôn mặt, không duplicate và lưu được vào cả PostgreSQL lẫn Qdrant.

1Admin upload face imagemultipart
2Backend stores objectemployee-faces/*
3Redis embedding jobemployee_id + image_key
4Worker creates embeddingDeepFace
5Persist metadata + vectorPostgreSQL + Qdrant
EnrollmentUpload -> embedding -> index

33 / Production Risks
Hardening
BiometricsKhuôn mặt là dữ liệu nhạy cảm; cần retention và quyền truy cập chặt.
ThresholdPhải hiệu chỉnh theo camera, ánh sáng, góc mặt và môi trường thật.
HTTPSBắt buộc nếu expose hệ thống ra ngoài local.
Rate limitChặn spam upload và brute-force login.
Audit adminGhi log thao tác tạo user, đổi role, xóa employee.
BackupPostgreSQL trước; sau đó MinIO bucket và Qdrant snapshot.
RiskFunctional MVP is not the same as production-ready
